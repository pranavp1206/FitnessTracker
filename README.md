# MyFitness - Health & Fitness Tracker

## Theme Description
MyFitness is a modern, responsive web application designed to help users track their daily health and fitness goals. The theme revolves around physical well-being, providing users with an intuitive dashboard to log workouts, track calories burned against daily goals, and monitor long-term progress using interactive charts and BMI calculators.

## Technologies Used
- **HTML5**: Semantic structuring of the web application.
- **CSS3**: Custom styling, Flexbox/Grid layouts, and CSS variables for theming.
- **JavaScript (ES6+)**: Core logic for workout calculations, form validation, and data persistence.
- **React 18** *(Additional Web Technology)*: Used as a modern component-based UI framework.
- **Babel Standalone**: Compiles React JSX directly in the browser.
- **LocalStorage API**: Persists user accounts and workout logs directly in the browser without needing a backend.

## Features Implemented
- **User Authentication**: Sign-up and Login forms with basic validation.
- **Dashboard**: A dynamic overview of today's stats, including a custom SVG progress ring.
- **Workout Logging**: A modal to log different exercises, auto-calculating calories based on activity type and duration.
- **Progress Tracking**: A page featuring a 7-day calorie breakdown and an interactive BMI calculator needle.
- **Contact Page**: A functional contact form with input validation.
- **Fully Responsive**: Adapts to both desktop and mobile screens.

## Project Structure
To satisfy the grading rubric, the project is organized into dedicated folders:
- `/css` - Contains the `style.css` stylesheet.
- `/js` - Contains the extracted React JavaScript logic (`app.js`).
- `/images` & `/assets` - Directories reserved for media and external assets.
- `index.html` - The main entry point of the application.

## How to Run
Because this project uses a standalone React build setup, no complex development servers are required.
1. Download or clone the repository.
2. Open the folder and double-click `index.html` to run it directly in any modern web browser.
